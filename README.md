# Aura`OS~2.5

Aura OS 2.5 is a lightweight web-based interface that works just like an operating system. It contains a notepad, a vault (which can be used for web shortcuts), a settings page to change the background, a terminal and most importantly, a python IDE (which is currently under development, it uses Pyodide).

## Requirements:

- A web browser with decent internet.... that's it.

Aura includes a lofi tracks module for light music. 
(Reminder: This is NOT a full fledged operating system and has only been created as a FUN-based project just out of curiosity.)

## How to run:

1. Go to webpage https://louisthegreat938-developer.github.io/web-os/
2. Enjoy! No downloads required.

## How it works:

Fully based on HTML, and uses pyodide for python (currently using py.3.11)

## Files:

If you want to view the code, you can simply open index.html
